# Матрица совместимости методов

Документ представляет собой спецификацию на уровне методов (method-level контракт),
описывающую совместимость с бэкендами, режимы маршрутизации, стратегии отката (fallback)
и сопутствующие семантические риски. Документ генерируется из
[capabilities.yaml](capabilities.yaml).

В документе рассматриваются семейства RPC, которые маршрутизируются (routed),
вызывают понижение версии (downgraded), транслируются через мост (bridged) или несут
потенциальные семантические риски, а не все пересекающиеся методы Apache HMS.
Локальные API токенов безопасности входного интерфейса (front-door-local security tokens)
по-прежнему описаны в [README.md](README.md).

Легенда статусов:

- `supported`: штатный режим работы для данной комбинации бэкенда и среды выполнения (backend/runtime)
- `degraded`: запрос выполняется с обратной трансляцией (downgrade), привязкой к default-catalog или возвратом совместимого ответа
- `rejected`: запрос отклоняется с явной ошибкой вместо эвристического подбора маршрута
- `unsafe`: запрос может маршрутизироваться, но многокаталожная семантика не является гарантированно безопасной для промышленной эксплуатации (production-safe) без предварительного тестирования

Обновить сгенерированную таблицу можно так:

```bash
mvn -o -q -Dtest=CapabilityMatrixDocSyncTest -Dcapabilities.updateReadme=true test
```
